## 修复：导航栏/主题自动切换/推荐框溢出
- 根因：Layout.vue 用 HomeLayout 完全替换默认 Layout，丢失 VPNav 导航栏。改为默认 Layout + `#home-hero-after` 插槽注入首页 + `#layout-bottom` 注入页脚；index.md 保持 layout: home（VPHome 无 hero/features 时不渲染，且 is-home 全宽 + overflow-x: clip）
- 主题自动切换：config 显式 `appearance: true`（默认 useDark initialValue 'auto' 已跟随系统）；enhanceApp 加 matchMedia change 监听（localStorage key `vitepress-theme-appearance`，仅无手动值/auto 时实时跟随）
- 溢出 bug 根因：`.top-grid` grid 子项默认 min-width:auto，被标签跑马灯 `width:max-content` 撑开整行溢出屏幕。修复：`.top-grid > * { min-width:0; max-width:100% }`、hero/recommend 卡片加 min-width:0+overflow:hidden、recommend-track 显式 width:100% + page flex:0 0 100%
