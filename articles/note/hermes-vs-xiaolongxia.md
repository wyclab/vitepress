为什么标题里有个小龙虾？因为性能优化和吃小龙虾有个共同点：**先剥壳最麻烦的那只，后面就顺了**。

## Hermes 是什么

Hermes 是 Meta 为 React Native 打造的 JavaScript 引擎，核心特点：

- 字节码预编译，跳过运行时 JIT 编译
- 启动时间显著缩短
- 内存占用更低

## 启发："小龙虾定律"

性能优化时，最大的误区是到处小修小补。正确的做法是：

1. **测量**：找到真正的瓶颈（往往是启动、首屏、包体积）
2. **摘除**：把"最贵的环节"整个拿掉（如 Hermes 跳过 JIT）
3. **验证**：用数据确认收益

## 结论

与其在细节里抠 5% 的优化，不如找到架构层面可以"整个剥掉"的那只小龙虾。
