# 模型介绍

> 这是一篇**概览型**的主流 AI 大模型速查手册（截至 2026 年 11 月），覆盖海外与国产十大核心阵营，重点梳理各家的**命名逻辑、产品定位、核心擅长领域与参考定价**。模型是 AI 系统的“大脑”（详见 [AI核心概念](/articles/ai/ai-tech/ai-concepts)），如果你想了解这些大脑在实际产品中如何落地干活，可配套阅读 [AI Agent介绍](/articles/ai/ai-tech/agent-intro)。

| 海外 | **OpenAI** | GPT-6 | 天文星体 | Luna（月）→ Terra（地）→ Sol（日）→ Astra（星） |
| 海外 | **Anthropic** | Claude 5 | 文学与史诗 | Haiku → Sonnet → Opus → Fable / Mythos |
| 海外 | **Meta** | Muse | 光与火花 | Glimmer（开源）→ Ember → Spark → Wonder |

## 海外主流模型

### Google：Gemini 4 系列

**命名逻辑**：放弃过去的 `Flash / Pro / Ultra`，改用 **Argon（氩）、Carbon（碳）、Hydrogen（氢）、Neon（氖）** 四种化学元素。元素名不按原子序数排座次，旨在**打破“越贵就全面越强”的线性错觉**——它们代表性能、速度与成本权衡曲线（帕累托前沿）上的不同生态位，适配高频模块化发布；全系标配 **1M 上下文**与**可调思考深度**（`low` / `medium` / `high` / `xhigh`）。社区常借直觉记忆：**氢**最轻快、**碳**最厚重硬核、**氖**明亮高效。

| 模型名称 | 核心定位 | 擅长什么 | API 定价（输入 / 输出，每百万 Tokens） |
| --- | --- | --- | --- |
| **Gemini 4 Hydrogen** | 极速高性价比执行引擎 | 日常高频开发、轻量脚本、多 Agent 并发子任务（Worker / Verifier），速度快、额度省 | `$1.50` / `$7.50` |
| **Gemini 4 Neon** | 全能“甜点级”主力（推荐默认） | 基于 Carbon 优化；复杂生产级编程、安全漏洞审计（SEC-bench Pro 90.5%）、数据分析与可控 Agent | `$3.00` / `$15.00` |
| **Gemini 4 Carbon** | 重型深度思考旗舰 | 超长链条推理、复杂架构设计、疑难调试、网络安全与前沿科研，常作多智能体总控“大脑” | `$2.00` / `$10.00`（12 月起 `$4.00` / `$20.00`） |
| **Gemini 4 Argon** | 首发前沿基座 | 奠定全系 1M 上下文与基线能力，主力场景现已逐步由 Carbon 和 Neon 细化承接 | 早期旗舰档位 |

> **选型速记**：跑量/子 Agent 选 **Hydrogen**，主力开发默认 **Neon**，啃最硬的架构/科研骨头再上 **Carbon**。

### OpenAI：GPT-6 系列

**命名逻辑**：告别早年 `GPT-4o` 与 `o1 / o3` 推理线分裂的混乱局面，GPT-6（及 6.1 / 6.2 迭代）将通用与深度推理合二为一，用拉丁语**天文星体**按体量由小到大清晰分档：**Luna（月）→ Terra（地）→ Sol（日）→ Astra（星）**。全系约 **1.05M 上下文**（输出上限 128K），并配套独立语音（`GPT-Realtime-2.1`）、图像（`GPT-Image-2.6`）以及开源权重 `gpt-oss` 系列。

| 模型名称 | 核心定位 | 擅长什么 | API 参考定价（输入 / 输出，每百万 Tokens） |
| --- | --- | --- | --- |
| **GPT-6 Luna** | 超低价高频轻量模型（免费版主力） | 文本分类、信息抽取、摘要、后台批处理与常规客服 | `$0.10` / `$0.50` |
| **GPT-6 Terra** | 均衡型生产中坚 | 日常办公自动化、常规写作、视觉理解与普通电脑操作 | 约 `$1.00` / `$5.00` |
| **GPT-6 Sol** | 甜点级主力（ChatGPT Plus 默认） | 日常高阶编程、文档分析与多步专业工作流，接近旗舰智力但成本大降 | `$2.00` / `$10.00` |
| **GPT-6 Astra** | 绝对旗舰（ChatGPT Pro 引擎） | 最难的专业推理、前沿科研、大型跨文件重构与高自主 Agent | `$8.00–$10.00` / `$40.00–$50.00` |

> **选型速记**：廉价批处理用 **Luna**，常规办公用 **Terra**，综合主力闭眼选 **Sol**，极限难题才动用 **Astra**。

### Anthropic：Claude 5 系列

**命名逻辑**：延续并扩展最具人文气息的**文学/史诗体裁命名**——**Haiku（俳句）→ Sonnet（十四行诗）→ Opus（巨作）→ Fable（寓言）→ Mythos（神话）**，体裁越宏大代表智力上限越深沉。全系支持 **1M 上下文**、128K 输出与自适应思考力度；其中 **Fable / Mythos** 为同底层的“双生超旗舰”，区别在于安全护栏与准入范围。

| 模型名称 | 核心定位 | 擅长什么 | API 参考定价（输入 / 输出，每百万 Tokens） |
| --- | --- | --- | --- |
| **Claude Haiku 5.5** | 极速经济型 | 低延迟路由、数据抽取、大规模分类与快速自动响应 | `$0.10` 起 / `$0.50` 起 |
| **Claude Sonnet 5.5** | 日常办公与开发主力 | 常规代码开发与修 Bug、写文档/PPT/表格、高频工具调用 Agent | `$2.00` / `$10.00` |
| **Claude Opus 5.5** | 重型编程与 Agent 旗舰 | 复杂多文件软件工程、严密逻辑编排与长周期知识工作（官方高阶默认起点） | `$4.00` / `$20.00` |
| **Claude Fable 5.2** | 公开可用的超旗舰推理模型 | 开放式科研探索、大型架构迁移，以及 Opus 仍搞不定的硬核难题 | `$8.00` / `$40.00` |
| **Claude Mythos 5.2** | 定向受控超旗舰 | 与 Fable 同源，面向经审核的生物/网络安全等机构定向开放 | 企业/定向授权 |

> **选型速记**：省钱提速用 **Haiku**，日常开发用 **Sonnet**，复杂工程选 **Opus**，顶尖攻关才上 **Fable**。

### Meta：Muse 系列

**命名逻辑**：由 Meta Superintelligence Labs（MSL）推出，以灵感女神 **Muse（缪斯）** 命名，标志着 Meta 从开源社区的 Llama 路线转向**原生多模态与消费级“个人超级智能”**（深度整合进 Meta AI、WhatsApp、Instagram 及 Ray-Ban 智能眼镜）。内部按**“微光 → 余烬 → 火花 → 奇观”**分层（注意 `Muse` 也用于助手 App、`Muse Code` 终端代理等产品名），核心特色是**视觉思维链**与**多子代理并行思考**。

| 模型名称 | 核心定位 | 擅长什么 | 形态 / 特点 |
| --- | --- | --- | --- |
| **Muse Glimmer（微光）** | 端侧开源小模型（30B） | 消费级硬件离线运行、端侧隐私处理与轻量推理 | 开源权重（SLM） |
| **Muse Ember（余烬）** | 轻量高效云端执行模型 | 高并发重复性 Agent 任务、意图路由、工具调用与信息抽取 | 低成本 API 档位 |
| **Muse Spark（火花，1.0–1.3）** | 原生多模态主力工作马 | 跨应用工具调用、电脑操作、视觉思维链与日常编程（含 `Spark Open` 开源版） | 1M 上下文、可调思考力度 |
| **Muse Wonder（奇观）** | 顶配前沿推理旗舰 | 复杂 STEM 推理、重型编码与高难度长程 Agent 编排 | 闭源旗舰档位 |

> **选型速记**：本地跑开源选 **Glimmer**，云端走量选 **Ember**，多模态与工具调用主力选 **Spark**，高难推理选 **Wonder**。

### xAI：Grok 4 系列

**命名逻辑**：“**Grok**”源自科幻小说《异乡异客》，意为“彻底领悟并融为一体”。马斯克旗下的 xAI（现属 SpaceXSI 生态）路线最务实，不搞花哨代号，在 **Grok 5**（训练中）到来前围绕 Grok 4 高频推进小数点迭代（`4.5 → 4.6 → 4.7`，`4.8` 在研）。最大特色是**深度联合 Cursor 打磨工程编程**，以及**原生接入 X（原 Twitter）实时数据流**与特斯拉车机生态。

| 模型名称 | 核心定位 | 擅长什么 | API 参考定价（200K 上下文内，每百万 Tokens） |
| --- | --- | --- | --- |
| **Grok Build / Fast** | 轻量极速开发线 | 极高输出速度、低延迟交互与经济型自动化脚本 | 输入约 `$1.00–$1.25` 起 |
| **Grok 4.20 / 4.3 变体** | 超长上下文特化版 | 1M–2M 级超大文档吞吐与海量资料检索分析 | 经济型档位 |
| **Grok 4.7（当前旗舰）** | 编程、推理与 Agent 主力旗舰 | 深度代码生成、数小时级自主任务（Grok Bot）、自我校验与实时热点分析（500K 上下文） | `$2.00` / `$6.00`（超 200K 翻倍） |

> **选型速记**：要极速选 **Fast / Build**，常规旗舰开发、编程与实时资讯分析直接用 **Grok 4.7**（输出单价在海外旗舰中很有优势）。

## 国产主流模型

### DeepSeek：V4 系列

**命名逻辑**：延续“极简硬核 + 开源普惠”风格。到了 **DeepSeek-V4** 世代，官方正式退役了早期分叉的 `deepseek-chat` / `deepseek-reasoner` 命名，收敛为两条清晰的 **MIT 开源** MoE 主线——**Flash** 与 **Pro**，均原生支持 **1M 上下文**与最高 384K 输出，并在 API 层面引入**峰谷分时定价**（非高峰时段半价，包含周末及中国法定节假日）。

| 模型名称 | 核心定位 | 擅长什么 | API 参考定价（非高峰 / 高峰，每百万 Tokens） |
| --- | --- | --- | --- |
| **DeepSeek-V4.1-Flash** | 高吞吐多模态编程/代理主力 | 552B MoE（低激活），原生视觉理解；高频 Agent 循环、代码生成与多轮对话性价比极高 | 输入 `$0.15 / $0.30`，输出 `$0.60 / $1.20` |
| **DeepSeek-V4-Pro** | 重型深度推理旗舰 | 1.6T MoE（激活 49B，纯文本）；密集知识召回、复杂逻辑推导与系统级架构规划 | 输入 `$0.66 / $1.32`，输出 `$1.98 / $3.96` |

> **选型速记**：日常编程、带视觉理解和高频 Agent 首选 **V4.1-Flash**；重度纯文本逻辑推理与架构设计选 **V4-Pro**；夜间或周末跑批量任务性价比拉满。

### 阿里通义千问：Qwen 4 / 3.8 系列

**命名逻辑**：采用最经典、易懂的**“大版本号 + 档位/专项后缀”**矩阵（`Max / Plus / Flash / Coder`）。产品策略走**“云端闭源旗舰 + 开源社区全尺寸覆盖”**双轨：顶配 **Qwen4-Max** 主打企业云端长程 Agent，而 **Qwen 3 / 3.8** 开源家族（Apache 2.0）则是全球开发者本地微调与端侧部署的常青树。

| 模型名称 | 核心定位 | 擅长什么 | 形态 / 特点 |
| --- | --- | --- | --- |
| **Qwen4-Max** | 阿里最新企业级旗舰 | 2.4T 稀疏 MoE（激活 ~71B）；原生图文视频多模态、数小时级自主编码、法律/金融分析与复杂 Agent | 1M 上下文、可调思考深度、云端 API |
| **Qwen Plus 系列** | 日常企业高性价比主力 | 通用问答、中文写作、常规办公与低延迟企业业务接入（如 Qwen 3.6/3.7 Plus） | 云端均衡档位 |
| **Qwen Coder 系列** | 软件工程专项线 | 代码仓库级生成、排错与终端自动化，深度集成 Qoder 与各类 IDE 插件 | 编程专项优化 |
| **Qwen Flash / Realtime** | 极速与实时交互线 | 低延迟全双工语音对话、流式音视频理解与高并发轻量任务 | 极速响应档位 |
| **Qwen 3 / 3.8 开源尺寸** | 开源社区主力（如 27B 等） | 私有化部署、垂直领域微调与本地原型验证 | Apache 2.0 开源权重 |

> **选型速记**：中文场景与复杂企业 Agent 上 **Qwen4-Max**，写代码找 **Coder**，要本地化部署和二次微调直接挑 **Qwen 3.8** 开源尺寸。

### 月之暗面：Kimi K3 系列

**命名逻辑**：以简洁的 **`K` 系列代数（K2 → K3 → K3.1）** 标识底层架构跃迁，用 **`Pro`** 标示高强度后训练旗舰、**`HighSpeed`** 标示极速生成版。早年以“超长无损上下文”出圈的 Kimi，在 2026 年全面退役 K2/K2.5 线，直接祭出全球首个 **3 万亿（3T）参数级开源 MoE** 架构（采用自研 Kimi Delta Attention），从性价比选手跃升为正面硬刚海外旗舰的第一梯队。

| 模型名称 | 核心定位 | 擅长什么 | API 参考定价（国际版，输入 / 输出，每百万 Tokens） |
| --- | --- | --- | --- |
| **Kimi K3** | 3T 级开源里程碑基座 | ~2.8T MoE（激活 104B），原生视觉 + 1M 上下文；面向科研与自托管的长程编码与知识工作 | 开源权重 / API `$3.00` / `$15.00` |
| **Kimi K3.1 Pro** | 当前主力旗舰 | 在 K3 基础上大幅降低幻觉；复杂工程开发（游戏引擎/CAD/3D）、金融建模、海量长文研报与 Agent 蜂群协作 | `$2.00` / `$10.00`（缓存输入 `$0.20`） |
| **Kimi K3.1 Pro HighSpeed** | 旗舰高速版 | 与 K3.1 Pro 同等智力，但输出速度提升 2–3 倍，适合对交互延迟敏感的重度任务 | `$4.00` / `$20.00`（缓存输入 `$0.20`） |

> **选型速记**：超长文档深度研判、低幻觉复杂编码与多 Agent 蜂群直接上 **K3.1 Pro**，追求丝滑响应选 **HighSpeed**（国内平台按人民币计费）。

### 智谱（Z.ai）：GLM-5 系列

**命名逻辑**：延续清华系学术背景的 **`GLM`（General Language Model）大版本 + 小数点快迭代**，轻量级缀以 **`Flash`**。2026 年的 GLM-5 家族（5.0 → 5.3）主打**“全栈国产算力训练（如华为昇腾）”**与**代理工程（Agentic Engineering）**，除了按量 API，还专门面向 Cursor / Claude Code 等开发者推出了包月不限心疼的 **GLM Coding Plan**；下一代 **GLM-6.0** 已明确聚焦“全自训练/递归自我进化（RSI）”路线（目前在研）。

| 模型名称 | 核心定位 | 擅长什么 | API 参考定价（输入 / 输出，每百万 Tokens） |
| --- | --- | --- | --- |
| **GLM-4.7-Flash** | 零成本轻量入门档 | 日常基础文本处理、简单问答与开发测试 | **官方 API 免费** |
| **GLM-5.3-Flash** | 高速低价开源生产主力 | ~320B MoE（激活 18B，MIT 许可）；高吞吐业务、快速原型与轻量 Agent | 输入约 `$0.15` 起 |
| **GLM-5.3（当前旗舰）** | 开源权重编码与代理工程旗舰 | ~753B MoE（激活 40B，1M 上下文）；经大规模异步强化学习，复杂软件工程、终端操作与安全能力顶尖 | 约 `$1.40` / `$4.40` |

> **选型速记**：想白嫖轻量 API 用 **GLM-4.7-Flash**，追求开源部署选 **GLM-5.3-Flash**，重度 AI 编程（或配合包月 Coding Plan）直接上 **GLM-5.3**。

### 字节跳动：豆包 Seed 2 系列

**命名逻辑**：底层研究归属字节 **Seed** 团队，对外品牌为国民级应用**豆包（Doubao）**，模型命名采用极直观的 **`Pro / Turbo / Code / Lite / Mini`** 梯度分层，并独创了 **`Seed-Evolving`** 滚动更新端点（开发者无需改模型 ID，火山引擎每周热更新能力）。国内依托**火山引擎**（最高 1M 上下文、人民币计价），海外通过 **BytePlus** 提供服务，整体以极强性价比和原生多模态体验著称。

| 模型名称 | 核心定位 | 擅长什么 | API 参考定价（每百万 Tokens） |
| --- | --- | --- | --- |
| **Seed 2.1 Lite / 2.0 Mini** | 极致低价走量档 | 大规模内容审核、摘要、分类与高并发后台任务 | 国内 Lite 约 `¥0.80` / `¥2.70`；海外 Mini 低至 `$0.10` / `$0.40` |
| **Seed 2.1 Turbo / 2.0 Code** | 高速均衡与编码专线 | 软件工程交付、低延迟交互与高频 Agent 执行循环 | 海外约 `$0.25–$0.50` / `$2.00–$2.50` |
