域名是博客的门面。当博客从一个域名迁移到另一个域名时，看似只是改一行配置，实际上涉及 DNS、构建配置、SEO 收录等一系列问题。

## 为什么换域名

- 旧域名续费成本过高
- 想统一个人品牌
- 旧域名历史解析记录混乱

## 更换流程

1. **购买新域名**：选择靠谱的注册商，注意隐私保护选项
2. **配置 DNS 解析**：将新域名 CNAME 或 A 记录指向部署平台
3. **更新站点配置**：修改部署平台的自定义域名设置
4. **设置 301 重定向**：在旧域名上配置永久重定向，保留权重
5. **提交搜索引擎**：更新 Search Engine Console 中的站点地址

## 踩过的坑

- CDN 缓存未刷新，导致新旧域名内容不一致
- 忘记更新 RSS 地址，订阅读者收到错误
- `robots.txt` 与 sitemap 未同步更新

总结：换域名不难，难的是"善后"。做好重定向与收录迁移，流量基本无损。
